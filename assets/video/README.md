# Video Assets

This directory is for hero video files.

## Recommended Video Specifications:
- **Format**: MP4 (H.264) and WebM (VP9) for best browser compatibility
- **Resolution**: 1920x1080 (Full HD) or higher
- **Aspect Ratio**: 16:9
- **Duration**: 15-30 seconds (looping)
- **File Size**: Keep under 5MB for web optimization
- **Framerate**: 24-30 fps

## Files Needed:
- `hero-video.mp4` - Main hero video (MP4 format)
- `hero-video.webm` - WebM version for better compression

## Video Content Suggestions:
- Logistics operations footage
- Trucks in motion
- Warehouse operations
- Technology dashboard animations
- Team collaboration
- Delivery processes

## Fallback:
If video files are not available, the hero section will display the poster image (`assets/img/logi.jpg`).
